# MovieExplorer

MovieExplorer es una aplicación web desarrollada con HTML, CSS y JavaScript.

## Características

- 🔍 Buscar películas y series.
- 🎬 Ver detalles completos.
- ⭐ Calificaciones.
- 👥 Reparto.
- 🖼️ Pósters e imágenes.
- 🎥 Tráilers (cuando estén disponibles).

## Requisitos

Para utilizar la aplicación necesitás una API Key gratuita de TMDb.

1. Crear una cuenta en https://www.themoviedb.org
2. Solicitar una API Key.
3. Abrir `app.js` y `detalle.html`.
4. Reemplazar:

const API_KEY = "TU_API_KEY";
